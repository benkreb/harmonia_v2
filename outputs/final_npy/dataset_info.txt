CBIS-DDSM MASS Dataset - Cropped-Image Pipeline
============================================================
Goruntu boyutu   : 256x256
Preprocessing    : Square Pad + Resize
Image type       : Cropped lesion mammogram
Toplam sample    : 1630
Toplam hasta     : 877
Sinif eslemesi   : BENIGN=0, MALIGNANT=1
Dtype            : uint8 (image 0-255, mask 0/255)

  test :  260 sample (132 patient) | BENIGN 154 / MALIGNANT 106 | area_ratio_mean=0.4388

Dosyalar:
